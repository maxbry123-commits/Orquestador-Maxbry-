01Global Navigation & Mode · 8 funciones

Logo click click
Volver al Home view.
Trigger: click sobre "⬢ MAXBRY" en la barra superior izquierda.
Global search ⌘K
Abre el command palette con fuzzy-search sobre 27+ comandos agrupados en 6 categorías (Navigation · Sessions · Profile · Skills · Marketplace · Mode).
Trigger: ⌘K / Ctrl+K, o click en la barra de búsqueda. Esc para cerrar.
Tabs principales (Home / Chat / Office / Profiles / Mobile / Pricing / README)
Navegación entre las 7 secciones principales. Active state highlighted en color accent.
Trigger: click en cualquier tab.
Reasoning chip
Cycle through reasoning levels: none → minimal → low → medium → high → xhigh. Cambia el reasoning_effort de la sesión activa.
Trigger: click en el chip "🧠 reasoning:high".
Profile chip
Cycle through 8 profiles preconfigured (quick → custom). Cuando llega a "custom" abre modal de Create Custom Profile.
Trigger: click en el chip "⚡ balanced".
Model chip
Cycle through 7 LLM providers (Sonnet 5 · Gemini 3 Pro · GPT-5 · DeepSeek V4 · Kimi 2 · MiniMax M3 · Qwen 3 Max). Switching sin restart.
Trigger: click en el chip "🎯 Sonnet 5".
Avatar (account)
Muestra el avatar del usuario. Click muestra toast (account menu en construcción).
Trigger: click en el avatar "M" circular arriba a la derecha.
Mode switch (Simple / Arquitecto)
Toggle entre Simple (3-panel chat) y Arquitecto (15 centers + live status table).
Trigger: click en "⚡ Simple" o "🏗️ Arquitecto" en la parte superior del Home.

02Home · Simple Mode · 6 funciones

8 Profile chips
Quick · Balanced · Professional · Research · Architect · Enterprise · Autonomous · + Custom. Cada uno con contador de expertos (1, 12, 24, 56, 84, 150, 300, custom). Status indicators: dot verde (idle) / amarillo (warn) / rojo (err).
Trigger: click en cualquier chip. Profile active cambia inmediato en headers.
Sessions panel (left)
Lista de 10 sesiones agrupadas por 📌 Pinned · 📅 Today · 📅 Yesterday · 📅 This week. Hover muestra acciones (📌 pin · 📦 archive · 🗑 delete). Botón "+ New" arriba a la derecha.
Trigger: click selecciona sesión, hover muestra acciones, click "+ New" crea session.
Chat panel (center)
Mensajes con thinking cards colapsables (click para expandir), tool call cards con resultados inline, dangerous command approval cards. Empty state con 4 sugerencias clickeables. Cada mensaje assistant tiene acciones Copy · Regenerate · Edit.
Trigger: type + Enter envía, click en thinking card colapsa.
Composer
Textarea + Attach (file picker nativo) + Voice (3s STT timeout) + Profile chip + Model chip. Token ring en vivo. Send (turquoise) ↔ Stop (warning) según estado.
Trigger: Enter envía, Shift+Enter salto de línea, click Attach abre file picker, click Voice activa 3s listening.
Empty state
Aparece solo si la sesión no tiene mensajes. 4 sugerencias: Audit API REST · Research MoE · Design microservices · FastAPI tests.
Trigger: click en cualquier sugerencia → autocompleta y envía.
Context panel (right)
Context ring SVG donut con % animado. Stats (Input · Output · Cache · Cost). Active skills list. Workspace tabs OpenClaw-Deck style (max 4).
Trigger: "Reset" arriba borra context, click en workspace tab "+ Add" añade tab (max 4).

04Multi-Session Chat · 7 columnas · 2 funciones

7 columnas simultáneas
Coder · Tester · Docs · Security · Research · Data · Designer. WebSocket-style streaming. Markdown rendering. Cada una independiente con su composer.
Trigger: escribir + Enter en cualquier columna envía a esa sesión.

05Office View · 4 funciones

▶ Start demo
Activa el ciclo de trabajo: agentes rotan entre idle/working/error cada 800ms. Status colors: idle=gris, working=amarillo, error=rojo pulsante. Conexiones visuales entre desks. Métricas live actualizan.
Trigger: click "▶ Start demo".
⏹ Stop
Detiene el ciclo. Los agentes mantienen su último estado.
Trigger: click "⏹ Stop".
💥 Random fail
Fuerza error aleatorio en 1 agente. Auto-recovery en 3s. Útil para testing de fault tolerance.
Trigger: click "💥 Random fail".
🔄 Reset
Vuelve todos los agentes a idle. Limpia estados de error y working.
Trigger: click "🔄 Reset".

06Profile Builder + Subsecciones · 8 funciones

📦 Export .tar.gz
Descarga el profile completo (name + model + reasoning + skills) como JSON formateado, listo para backup o sharing.
Trigger: click "📦 Export .tar.gz" en Profile Builder header.
📋 Clone
Crea "{profile}-copy" basado en el actual, y lo activa.
Trigger: click "📋 Clone".
🗑 Delete
Elimina el profile actual. Bloqueado si es "balanced" (default).
Trigger: click "🗑 Delete".
Wizard 5-step (🧬 Wizard tab)
① Identity (name, avatar, prompt) → ② Model/Provider (dropdown selecciona modelos según provider) → ③ Skills (checkboxes 13) → ④ MCP (catálogo + custom URL) → ⑤ Review con YAML preview → Deploy sin restart.
Trigger: click en wizard steps 1-5 o "Next →" avanza, "← Back" retrocede, "✓ Deploy profile" deploya.
⚡ Skills tab
13 skills con toggle ON/OFF individual. Counter en tab cuenta activos. Enable all / Disable all / Install new.
Trigger: click toggle o "Enable all" / "Disable all" / "📥 Install new".
🧠 LLM Registry tab
8 LLM providers: OpenAI GPT-5 · Anthropic Sonnet 5 · Google Gemini 3 Pro · DeepSeek V4 · Kimi 2 · MiniMax M3 · Qwen 3 Max · Ollama local. Test · Configure · Remove.
Trigger: click "🧪 Test" simula request, "⚙️" abre config, "🗑" elimina.
🔌 MCP Servers tab
17 MCP servers: Obsidian · Graphiti · Baidu OCR · GitHub · GitLab · Drive · Gmail · Outlook · Filesystem · Telegram · Discord · Slack · Notion · PostgreSQL/MySQL/Redis · Qdrant/Milvus/Chroma/Neo4j · REST/GraphQL · Calendar.
Trigger: click toggle ⏸/▶ cambia conectado/desconectado, "⚙️" abre config.
🎛️ Parameters tab
8 sliders live: Temperature · Top-P · Top-K · Max output tokens · Reasoning effort · Consensus strength · Reranker K · Cache TTL. Cambios sin reset, afectan nuevas requests.
Trigger: drag cualquier slider → valor se actualiza en label.
