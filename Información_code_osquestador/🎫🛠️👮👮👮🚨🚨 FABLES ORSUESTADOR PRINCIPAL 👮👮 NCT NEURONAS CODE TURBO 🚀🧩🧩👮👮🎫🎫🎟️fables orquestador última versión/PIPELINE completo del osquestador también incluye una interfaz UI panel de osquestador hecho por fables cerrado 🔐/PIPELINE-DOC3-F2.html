planner_offline.py existe (H4): compilador Python puro sin LLM, orden topológico real, salida congelada con hash — patrón "planificar offline, ejecutar ciego". EXTENSIONES nuevas: (1) safe_eval para el campo condition (AST restringido: ast.Call y ast.Import prohibidos — anti-inyección, PARCHE_G06); (2) capability_registry con cadena de resolución en 3 pasos que consulta resources.yaml (propuesta DeepSeek) antes de crear fichas; (3) regla de ficha aplicada como validador: 1 ficha = 1 función, ≤200 LOC, PROHIBIDO runtime/orquestador/DAG/FSM dentro de una ficha (el validador rechaza el plan si una ficha viola esto); (4) las 325 fichas mapeadas entran como catálogo inicial del registry (30 con código → estado "real", 295 → "planeada").
Simple: F2 escribe la receta completa antes de cocinar: qué pasos, en qué orden, cuáles en paralelo, qué hacer si uno falla — y la sella con huella para que nadie la cambie a mitad de camino. Antes de inventar una herramienta nueva, pregunta tres veces: ¿ya la tiene el staff? ¿ya existe gratis? Solo si no, se fabrica.
