⚙️ Explicación técnica

El vagón se construye como proceso supervisor independiente (no coroutine dentro de F4 — si F4 muere, F5 sigue vivo para reportarlo). PAD implementa el modelo pleasure-arousal-dominance como métricas derivadas (ritmo de tokens, tasa de error, varianza de outputs) — 0% IA, solo umbrales. Ansiedad detecta "duda circular": mismo par pregunta-respuesta interna ≥2 veces (hash de intentos). Anti-drift calcula divergencia KL entre distribución de acciones planeadas (sequence.json) y ejecutadas (eventos) en ventana móvil. LOOPS-INFRA se extrae del loop_engine (separación declarada en V5/CAMBIOS-BASE): heartbeat, señales de sistema, dead-letter con jitter exponencial, y el meta-loop que vigila a los propios loops. Sentinel_Security es tabla de reglas + emisor de eventos tipados — la reacción la decide F8, no este vagón (vigilar ≠ reparar).
🎄 Simple: mientras los elfos trabajan, tres vigilantes nocturnos recorren el taller: uno mira las reglas, otro toma el pulso cada 30 segundos, y el tercero nota si un elfo está nervioso, da vueltas en círculo o se desvió del plano. Si ven algo raro, no gritan al jefe de una — primero cambian la táctica; solo escalan con campana si de verdad hace falta.
