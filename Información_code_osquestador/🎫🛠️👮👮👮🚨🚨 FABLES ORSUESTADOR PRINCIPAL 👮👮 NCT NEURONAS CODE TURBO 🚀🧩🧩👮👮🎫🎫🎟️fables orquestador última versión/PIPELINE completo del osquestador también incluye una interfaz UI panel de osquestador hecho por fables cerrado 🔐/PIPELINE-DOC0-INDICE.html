3 · REGLAS GLOBALES DE CONSTRUCCIÓN (aplican a TODOS los docs)

LOC: ≤150 ideal · 150–300 máximo normal · 300–500 SOLO con justificación escrita en la ficha · >500 PROHIBIDO (fragmentar). Cohesión > conteo.
Anti-pérdida: cada paso numerado lleva su fuente (#GAP-xxx o documento) — traza bidireccional verificable por script; gap sin paso = FAIL del doc.
Copiar antes que escribir: si la pieza existe (columna "copiar" de cada doc), Sonnet recibe la RUTA y copia. Re-generar código existente = violación.
Formato de salida de cada paso (formato UOOS Parte 1 §7): ruta + código completo copiable ≤90 chars/línea + comando de verificación + evidencia §6.4 {archivos @hash, tests PASS/FAIL, score}. Segmentos >80 líneas → bloques ~60 numerados.
Despliegue por partes: al cerrar cada DOC, se corre el despliegue determinista v2.0 SOLO de ese bloque (dry-run→OK Director→push→verificar.py). Se construye y se despliega por tramos, nunca todo al final.
Ejecución: todo el paquete corre bajo UOOS Parte 2 v3 (E01-E12 + RT-00→RT-90). Cada DOC = un tramo del DAG; cada paso = un nodo con contrato.
