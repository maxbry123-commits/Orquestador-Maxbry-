Las 5 Piezas del Cerebro (cerrado en G2 v2.5)

CERRADO
PIEZA 1 · ROUTER
Router Dispatcher
Match de tags sin IA. Despacha fichas a su pool según runtime_type (compute / hybrid / llm / agent).
PIEZA 2 · ÍNDICE
Índice Maestro
master_index + semantic_index caché local. FAISS en BRAIN. Spaces reciben embeddings como input, no acceden a FAISS.
PIEZA 3 · MOTOR DAG
Motor DAG + Topological Sort
Calcula orden de ejecución de fichas. Validación de ciclos. depends_on entre fichas (no entre pasos).
PIEZA 4 · RECOVERY CORE
Recovery Core (250KB · 5 tiers)
Tiers: constitution / blueprints / artifacts / states / metadata. WAL append-only. Checkpoint cada 1000 entries o 60s.
PIEZA 5 · LOADER+VERIFIER+EXECUTOR
Triple: Cargar · Validar · Ejecutar
Loader carga ficha validada. Verifier N0→N5 valida. Executor la corre. Reporta a CrazyWall atómicamente.

4 capas internas

  • KERNEL — constitution + router + triage
  • RUNTIME — agents + daf + reasoning + spaces + execution
  • VERIFICATION — gcl_v1 + gcl_lite + audit + tests
  • STATE — recovery_core + FAISS + registry + WAL

Execution Layer

  • LOCAL: importlib + asyncio.wait_for
  • HF: httpx + Bearer HF_API_TOKEN
  • REMOTE: mismo contrato (futuro)

Verifier N0→N5

  • N0: GPG firma
  • N1: hash + revocation
  • N2: schema + imports whitelist
  • N3: version
  • N4: compat con kernel
  • N5: AST ratio + diff

Cerrado en G2 v2.5 AUDITADO

NO SE REABRE

18 puntos cerrados — no se reformulan

  1. Cerebro = 5 piezas (Router+Índice+DAG+Recovery+Execution).
  2. DAG = ejecución fichas / FSM = gobernanza.
  3. Reliquias eliminadas: HFSM, BehaviorTree, GOAP-MAXBRY, CCL 20 capas, 14 motores F-1, 7 motores críticos, 5 técnicas ML, NeuronCore, Pattern Scanner.
  4. 1 ficha = 1 función ejecutar(input).
  5. Verifier N0→N5 (GPG → hash → schema → version → compat → AST).
  6. Slot Contract SC1-SC6 antes de cualquier artifact.
  7. FAISS en BRAIN, Spaces NO lo acceden.
  8. shared_knowledge BINARIO (COMMITTED o no existe).
  9. Crazy Wall escritura atómica: mkstemp + fsync + replace.
  10. 13 reglas absolutas.
  11. WAL + checkpoint dual (1000 entries OR 60s).
  12. GCL-lite O(1) por fase / GCL v1.0 gate final de F4.
  13. Stack: Python 3.11+, faiss-cpu==1.7.4, z3-solver==4.12.4, typer[all], httpx[asyncio], gnupg.
  14. MVP: 5 pasos (Runner local + sequence.json → DAG → state.json → 1 ficha real + 1 ficha fallo → orquestador → trace_id+JSONL).
  15. runtime_type ∈ {compute, hybrid, llm, agent}. Agent requiere max_steps, allowed_actions, environment, requires_approval, agent_source.
  16. 3 archivos por ficha: [nombre].py + [nombre].meta.md + artifact_location_plan.json.
  17. El índice NUNCA escanea código. Solo lee artifact_manifest.json.
  18. Lista cerrada de agentes Categoría B. ADR obligatorio para añadir.
