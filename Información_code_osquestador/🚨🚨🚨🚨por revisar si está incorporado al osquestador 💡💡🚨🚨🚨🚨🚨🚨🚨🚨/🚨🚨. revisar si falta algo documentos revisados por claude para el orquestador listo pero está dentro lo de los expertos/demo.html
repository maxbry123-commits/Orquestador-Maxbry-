02Home · Simple Mode
6 funciones
8 Profile chips
Quick · Balanced · Professional · Research · Architect · Enterprise · Autonomous · + Custom. Cada uno con contador de expertos (1, 12, 24, 56, 84, 150, 300, custom). Status indicators: dot verde (idle) / amarillo (warn) / rojo (err).
Trigger: click en cualquier chip. Profile active cambia inmediato en headers.
Sessions panel (left)
Lista de 10 sesiones agrupadas por 📌 Pinned · 📅 Today · 📅 Yesterday · 📅 This week. Hover muestra acciones (📌 pin · 📦 archive · 🗑 delete). Botón "+ New" arriba a la derecha.
Trigger: click selecciona sesión, hover muestra acciones, click "+ New" crea session.
Chat panel (center)
Mensajes con thinking cards colapsables (click para expandir), tool call cards con resultados inline, dangerous command approval cards. Empty state con 4 sugerencias clickeables. Cada mensaje assistant tiene acciones Copy · Regenerate · Edit.
Trigger: type + Enter envía, click en thinking card colapsa, click en chat-suggestion autocompleta.
Composer
Textarea + Attach (file picker nativo) + Voice (3s STT timeout) + Profile chip + Model chip. Token ring en vivo (96k/128k format). Send (turquoise) ↔ Stop (warning) toggle según estado.
Trigger: Enter envía, Shift+Enter salto de línea, click Attach abre file picker, click Voice activa 3s listening.
Empty state
Aparece solo si la sesión no tiene mensajes. 4 sugerencias clickeables: Audit API REST · Research MoE · Design microservices · FastAPI tests.
Trigger: click en cualquier sugerencia llena el composer con el prompt y envía.
Context panel (right)
Context ring SVG donut con % animado. Token stats (Input · Output · Cache · Cost). Active skills list. Workspace tabs OpenClaw-Deck style (max 4).
Trigger: "Reset" arriba a la derecha borra context, click en workspace tab "+ Add" añade tab (max 4).

05Office View
4 funciones
▶ Start demo
Activa el ciclo de trabajo: agentes rotan entre idle/working/error cada 800ms. Status colors: idle=gris · working=amarillo · error=rojo pulsante. Conexiones visuales entre desks. Métricas live actualizan.
Trigger: click "▶ Start demo".
⏹ Stop
Detiene el ciclo. Los agentes mantienen su último estado (working/error visibles).
Trigger: click "⏹ Stop".
💥 Random fail
Fuerza error aleatorio en 1 agente. Auto-recovery en 3s (transición error → idle). Útil para testing de fault tolerance.
Trigger: click "💥 Random fail".
🔄 Reset
Vuelve todos los agentes a idle. Limpia estados de error y working.
Trigger: click "🔄 Reset".

Trigger: click en wizard steps 1-5 o "Next →" avanza, "← Back" retrocede, "✓ Deploy profile" deploya.

13 skills con toggle ON/OFF individual. Counter en tab cuenta activos. Enable all / Disable all / Install new (abre modal).

8 LLM providers pre-configurados (OpenAI GPT-5 · Anthropic Sonnet 5 · Google Gemini 3 Pro · DeepSeek V4 · Kimi 2 · MiniMax M3 · Qwen 3 Max · Ollama local). Test · Configure · Remove (excepto OpenAI que es default).
Trigger: click "🧪 Test" simula request, "⚙️" abre config, "🗑" elimina provider.

🎛️ Parameters tab
8 sliders live: Temperature · Top-P · Top-K · Max output tokens · Reasoning effort · Consensus strength · Reranker K · Cache TTL. Cambios sin reset, afectan nuevas requests.
