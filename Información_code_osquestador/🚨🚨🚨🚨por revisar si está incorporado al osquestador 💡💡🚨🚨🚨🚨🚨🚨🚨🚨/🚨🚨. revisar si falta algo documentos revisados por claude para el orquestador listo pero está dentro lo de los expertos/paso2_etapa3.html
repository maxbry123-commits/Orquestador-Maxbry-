SelfCheckGPT
Paper2023

Qué es

Método de detección de alucinaciones: muestrea N respuestas del mismo modelo y mide inconsistencia.

Qué借鉴

El patrón de sampling + consistency check: si N respuestas del mismo modelo se contradicen, hay alta probabilidad de alucinación.

Aplicación a MAXBRY

Tu Hallucination Checker muestrea 5 variantes del output y mide inconsistencia. Si > 30% se contradicen → marca como sospechoso.

Guardrails AI
Framework

Qué es

Framework de validación de outputs con RAIL (Reliable AI Markup Language) — especifica qué debe tener el output.

Qué借鉴

El patrón de spec-driven validation: defines un contrato (qué artefactos, qué formato, qué campos), el sistema valida contra él.

Aplicación a MAXBRY

Tu Output Contract usa Pydantic + reglas custom para validar que el output cumple exactamente lo esperado.

HHEM (Hughes Hallucination Evaluation Model)
PaperVectara

Qué es

Modelo open-source especializado en detectar si un resumen está respaldado por el documento fuente.

Qué借鉴

El patrón de groundedness check: ¿cada claim del output está respaldado por evidencia?

Aplicación a MAXBRY

Tu Evidence Checker usa HHEM-style: cada claim del output debe tener source reference verificable.

NLI Models (DeBERTa)
ModelMicrosoft

Qué es

Modelos de Natural Language Inference que detectan si dos frases se contradicen, se implican o son neutrales.

Qué借鉴

El patrón de pairwise consistency: comparar cada par de claims del output con NLI.

Aplicación a MAXBRY

Tu Consistency Checker usa DeBERTa-NLI para detectar contradicciones internas en el output.

JSON Schema + Pydantic
SpecStandard

Qué es

Estándares de validación de estructura de datos.

Qué借鉴

El patrón de strict structural validation: el JSON output debe cumplir exactamente el schema.

class OutputPipeline:
    """10 checks binarios ejecutados en paralelo."""

    def __init__(self):
        self.checkers = [
            FormatController(),
            CompletenessChecker(),
            EvidenceChecker(),
            GoalChecker(),
            JSONValidator(),
            MarkdownBuilder(),
            ReportBuilder(),
            ConsistencyChecker(),
            HallucinationChecker(),
            FinalJudge(),
        ]

    async def validate(
        self, 
        artifacts: list["Artifact"], 
        contract: "OutputContract",
        original_goal: "Goal"
    ) -> "ValidationReport":
        state = ValidationState(
            artifacts=artifacts,
            contract=contract,
            goal=original_goal,
            results={},
        )
        # Cada check devuelve PASS o FAIL con issues
        for checker in self.checkers:
            result = await checker.check(state)
            state.results[type(checker).__name__] = result
            if result.status == "FAIL" and result.is_blocking:
                state.escalate = True
                break

        return ValidationReport(
            state=state,
            approved=all(r.status == "PASS" for r in state.results.values()),
            issues=[i for r in state.results.values() for i in r.issues],
        )

Hallucination Detection (SelfCheckGPT)
class HallucinationChecker:
    """借鉴 SelfCheckGPT: muestrea N respuestas y mide inconsistencia."""

    SAMPLES = 5
    THRESHOLD = 0.30

    async def check(self, output: str) -> "CheckResult":
        # 1. Generar N variantes del mismo output
        variants = await asyncio.gather(*[
            self._regenerate(output) for _ in range(self.SAMPLES)
        ])

        # 2. Medir inconsistencia entre variantes con NLI
        contradictions = 0
        for i in range(len(variants)):
            for j in range(i + 1, len(variants)):
                if await self._nli_contradicts(variants[i], variants[j]):
                    contradictions += 1

        total_pairs = len(variants) * (len(variants) - 1) // 2
        inconsistency = contradictions / total_pairs

        return CheckResult(
            check="no_hallucinations",
            status="FAIL" if inconsistency > self.THRESHOLD else "PASS",
            inconsistency_score=inconsistency,
        )

class OutputRepair:
    """Si un check falla, intenta reparar 1 vez antes de escalar."""

    async def repair(self, output: str, issues: list[str]) -> str:
        prompt = f"""The following output has these issues:
{chr(10).join(issues)}

Original output:
{output}

Please fix ONLY the issues listed, keeping everything else the same.
Return the corrected output."""
        fixed = await self.llm.invoke(prompt)
        # Re-validar
        new_issues = await self._re_validate(fixed)
        if not new_issues:
            return fixed
        # Si sigue fallando, escalar
        raise UnrepairableError(new_issues)

Audit Log Inmutable
class AuditLog:
    """Hash-chained log inmutable de cada output (借鉴 kbot-finance)."""

    def __init__(self):
        self._chain: list["AuditEntry"] = []
        self._last_hash = "0" * 64

    def append(self, entry: "AuditEntry") -> None:
        import hashlib
        payload = f"{self._last_hash}|{entry.timestamp}|{entry.action}|{entry.actor}"
        new_hash = hashlib.sha256(payload.encode()).hexdigest()
        entry.prev_hash = self._last_hash
        entry.hash = new_hash
        self._chain.append(entry)
        self._last_hash = new_hash

    def verify_integrity(self) -> bool:
        """Recorre toda la cadena y verifica que ningún hash fue alterado."""
        for i, entry in enumerate(self._chain):
            expected = hashlib.sha256(
                f"{entry.prev_hash}|{entry.timestamp}|{entry.action}|{entry.actor}".encode()
            ).hexdigest()
            if expected != entry.hash:
                return False
        return True
